# AI Avisen prototype

Dette repo indeholder et første bud på et PHP-baseret layout til en kurateret AI-nyhedsavis. Forsiden illustrerer avisens sektioner, tag-filtrering og roadmap for den fremtidige automatiserede platform.

## Struktur

- `index.php` – genererer forsiden med eksempeldata og sektioner.
- `partials/` – genanvendelige kort-komponenter til top- og standardartikler.
- `assets/styles.css` – avisinspireret styling.
- `assets/app.js` – simpel tag-filtrering på klientsiden.

Upload filerne til din PHP-server for at se prototypen, og udskift eksempeldataene med feeds eller databaseindhold, når backend-logikken er klar.
